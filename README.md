# an-history

按域名分组管理浏览器历史记录的 Chrome 扩展。接管 `chrome://history`，提供组内按时间倒序、单条/整组/批量删除，并清理地址栏的历史补全来源。

## 功能

- 接管 `Ctrl+H`、菜单「历史记录」、地址栏 `chrome://history`
- 界面仿照 Chrome 原生历史页：顶部居中搜索框、左侧导航、居中圆角卡片、勾选后顶栏切换为「已选择 N 项」
- 两种视图：「按网站」（默认，一个网站一张卡片）和「按时间」（与原生页一样按日期分卡片）
- 「按时间」支持自定义时间范围：选择开始/结束日期即可只显示该区间内的记录
- 左侧网站列表（站点图标、记录条数、筛选）；每条记录的 ⋮ 菜单提供「更多来自此网站的记录」「复制链接」「从历史记录中移除」
- 组内按 `lastVisitTime` 倒序；网站卡片按最近访问排序（可切 A–Z）
- 标题 / 网址搜索，`/` 或 `Ctrl+F` 聚焦；Shift+点击复选框可连续多选，`Delete` 删除所选
- 删除单条（该 URL 全部访问）、删除整组、多选批量删除，均有影响范围确认；批量删除先更新界面，再在后台完成，进度显示在顶栏
- 深色模式、站点图标、虚拟滚动（10 万条级别）；窄窗口时侧边栏收起为抽屉；滚动条贴在历史卡片右侧
- 全部数据本地处理，零网络请求

## 安装（加载已解压）

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`an-history`）
4. 按 `Ctrl+H`，应看到按域名分组的新历史页

> Chrome 137 起已移除命令行 `--load-extension`，因此只能通过上面的方式手动加载一次。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `history` | 读取、删除历史记录 |
| `favicon` | 显示站点图标 |
| `storage` | 预留（设置项） |

不申请 `tabs`、`<all_urls>`，不发送任何网络请求。

## 文件结构

```
manifest.json     MV3 清单，chrome_url_overrides.history
history.html/css  历史页界面
app.js            页面逻辑：分组、虚拟列表、搜索、删除
db.js             IndexedDB 镜像（entries / meta）
sync.js           全量分页构建 + 增量同步
entry.js          HistoryItem 归一化（仅 http/https）
background.js     Service Worker：实时增量、工具栏/快捷键入口
icons/            应用图标
```

## 已知限制

- 只能按 URL 删除，删除的是该 URL 的**全部**访问记录（API 不支持删除单次 visit）
- 删除历史只消除「历史来源」的地址栏补全；书签、搜索联想、表单自动填充不受影响
- Edge 不支持覆盖 `history` 页，可用工具栏按钮或 `Ctrl+Shift+H` 打开独立页面
